## 🌟 Overview

Welcome to my personal portfolio repository! This website is an immersive, interactive portfolio crafted with modern web technologies and 3D graphics to showcase my work, technical skills, and achievements.

### Key Highlights
- **Interactive 3D Visuals**: Three.js particle systems, dynamic shaders, and interactive mouse-following physics.
- **Fluid Animations**: Smooth page transitions, typography animations, and micro-interactions powered by GSAP.
- **Curated Projects**: Detailed highlights of production and research projects in Artificial Intelligence, Computer Vision, and Full-Stack Engineering.
- **Embedded Resume**: Direct download of my latest resume (`Tanishka_Vashisth_Resume.pdf`).

---

## 🛠️ Tech Stack

- **Frontend & Visuals**: HTML5, Modern CSS3, Vanilla JavaScript (ES6+)
- **3D & Creative Coding**: Three.js, WebGL
- **Animation & Transitions**: GSAP (GreenSock Animation Platform), ScrollTrigger
- **Hosting & CI/CD**: GitHub Pages

## 🚀 Local Development

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tanishka180405/Portfolio.git
   cd Portfolio
   ```

2. **Open in browser:**
   - Double-click `index.html` to open it directly in your browser, or
   - Use a local server (e.g. VS Code Live Server extension or `python -m http.server 8000` and visit `http://localhost:8000`).
